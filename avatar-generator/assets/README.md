# assets/

Everything here is created by the scripts and git-ignored:

| Folder | Created by | Contents |
|---|---|---|
| `vendor/` | `scripts/fetch_assets.py` | `mpfb.zip` (MPFB 2.0.18 add-on), `mh_cc0.zip` (MakeHuman CC0 system assets), both sha256-verified |
| `blender-user/` | `scripts/fetch_assets.py` | A private Blender profile (`BLENDER_USER_RESOURCES`) with MPFB installed and the MakeHuman assets unpacked |
| `generated/` | each build | Graded skin, tinted hair, brows and lashes, iris, hair-strand texture, prints, flag patch, watch faces, fabric normal maps, game-quality atlases and palettes (CC0) |
